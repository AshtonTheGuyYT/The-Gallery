To start the HTML, open this folder in CMD (open CMD or pres the file directory at the very top, 
should say "This PC > (install location) > nudegallery" or whatever u name this) 
and type CMD while replacing everything else. It'll keep it there and open the Command Panel.


While in the Command Panel, paste this into it:

php -S localhost:8000

Once you type that, it should say something like "PHP (version) Development Server (https://localhost:8000) started"
Now, open your chrome browser, and type http://localhost:8000 and it should work!
Enjoy, and feel free to customize the HTML to your hearts content!! :3
